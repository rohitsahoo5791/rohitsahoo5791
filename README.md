<details>
<summary>Performance investigation workflow</summary>

1. Establish a repeatable baseline under a defined load profile.
2. Identify the request path and the likely source of latency.
3. Test one change at a time, such as HTTP or Redis caching.
4. Compare latency, throughput, and error rate with the baseline.
5. Document trade-offs, invalidation strategy, and next experiments.
</details>
